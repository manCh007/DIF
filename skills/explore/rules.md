# explore — project-specific overrides

This file is read by the `explore` skill on every run, after the defaults in `SKILL.md`. It ships near-empty by design — edit it directly in your project's copy of this plugin (or override it entirely by creating `.claude/skills/explore/rules.md` at the project level, which takes precedence — see SETUP.md §5). Nothing below is required; uncomment/edit only what you need.
